## 🌟 Tentang BiConnect

**BiConnect** adalah platform jaringan kolaborasi akademik dan sosial yang dirancang khusus untuk menghubungkan mahasiswa **Universitas Bina Sarana Informatika (BSI)**. Platform ini mewadahi mahasiswa untuk berbagi proyek kolaboratif, mencari rekan tim dengan keahlian khusus, dan membangun komunitas ilmiah di lingkungan kampus.
